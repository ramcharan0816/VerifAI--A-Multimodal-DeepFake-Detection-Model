Frequently Asked Forensic Questions

How does VerifAI achieve 94.62% detection accuracy? +
VerifAI utilizes an optimized PyTorch MobileNetV3-Small convolutional neural network trained on over 100,000 balanced benchmark samples from FaceForensics++, Celeb-DF v2, and the Deepfake Detection Challenge (DFDC). Predictions are further validated by multimodal evidence fusion including 2D Fast Fourier Transform frequency domain analysis and Error Level Analysis (ELA).
What is Grad-CAM and how does it explain model decisions? +
Gradient-weighted Class Activation Mapping (Grad-CAM) computes the gradients of the model's classification score with respect to the final convolutional feature layer. By pooling these gradients, VerifAI generates an authentic spatial heatmap pinpointing the precise pixels and facial regions that triggered the REAL or FAKE classification.
Does VerifAI store or retain uploaded investigative media? +
VerifAI adheres to strict enterprise privacy protocols. Uploaded media is processed entirely within a localized secure sandbox. Users retain full cryptographic custody with local SHA-256 provenance hashes and can purge history records at any time.

How VerifAI Works: 4-Stage Architectural Pipeline

From user image ingestion to PyTorch tensor extraction, explainable Grad-CAM backpropagation, and multimodal evidence fusion.

01

Media Ingestion

Client uploads image to FastAPI backend. System computes SHA-256 cryptographic checksum, validates MIME type (JPG/PNG/WEBP), and extracts hardware camera EXIF provenance.

02

260×260 Tensor Normalization

PyTorch transforms resize input to exact 260×260 RGB dimensions, convert to float32 tensors, and apply ImageNet zero-centered standard normalization (mean & std).

03

MobileNetV3 Inference

Forward pass traverses 12 Inverted Residual blocks with Squeeze-and-Excitation attention and Hard-Swish activations to extract spatial feature maps and logits for REAL vs FAKE.

04

Evidence Fusion & Grad-CAM

Hooks layer 12 gradients to generate authentic Grad-CAM heatmaps, computes 2D FFT magnitude spectrum and ELA compression differential, and saves verdict to SQLite.

Underlying Deep Learning Innovations

Inverted Residuals & Linear Bottlenecks

MobileNetV3 utilizes inverted residual blocks that expand input representations to higher dimensions before depthwise separable convolutions, then project back to lower dimensions with linear activations. This preserves critical high-frequency boundary textures without manifold destruction.

Squeeze-and-Excitation (SE) Attention

SE blocks dynamically re-weight channel-wise feature responses by modeling interdependencies between channels. In deepfake forensics, this allows the network to focus attention selectively on chromatic aberrations and boundary seams around facial perimeters.

Abstract & System Overview

VerifAI is a multimodal deepfake tracing and detection system developed to identify, analyse, and explain manipulated digital media, including images, videos, and audio files. The rapid growth of artificial intelligence-based generation and editing tools has made it increasingly difficult to distinguish authentic content from synthetic or altered media. Such content can be used to spread misinformation, commit identity fraud, manipulate public opinion, and create misleading digital evidence. Conventional verification methods generally depend on manual inspection or single-modality detection models. These approaches may be slow, difficult to scale, vulnerable to new generation techniques, and unable to provide a clear explanation for their decisions. VerifAI addresses these limitations through a unified, evidence-based forensic workflow.

The system combines several complementary forms of analysis. The visual analysis module examines facial structure, skin texture, blending boundaries, lighting, shadows, reflections, and other spatial artefacts that may indicate manipulation. For audio-based media, the system analyses spectrograms and acoustic characteristics to identify synthetic voice patterns. Metadata analysis further examines file information, encoding details, timestamps, and compression traces that reveal editing history.

The outputs of these specialised modules are combined by an evidence fusion engine. Instead of relying on one prediction, the engine integrates the available signals to generate a single authenticity verdict, such as Real or Manipulated, along with a confidence score and an evidence breakdown. Heatmaps, timelines, and module-level scores help users understand which features influenced the decision rather than receiving only an unexplained classification.
